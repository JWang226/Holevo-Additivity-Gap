# Finite realization and dimensions

Choose the local size $N=\lceil\exp(40(7\ln K+2)n)\rceil$ and the proof's moment order. The threshold $n\ge n_0(K)$ makes all coefficient-size, moment, and tolerance requirements compatible.

[explicitHaarExpectation](lean:Nonadditivity.HaarPrescribedDimension.explicitHaarExpectation) supplies the finite norm comparison. A favorable sample for the combined net polynomial then yields the uniform adjoint estimate with $t=\kappa_n c(K,n)$.

The [certificate theorem](lean:Nonadditivity.StructuredHaarConsequences.exists_explicit_certificate) accepts an expectation comparison as a premise; the final channel assembler supplies that premise. This explains why the map can show expectation and certificate results as parallel inputs to the assembler.

The main endpoint retains one actual channel's input dimension $2N^nK^{2n}$, output dimension $K^n$, and a positive single-use lower bound. Read [the construction chapter](guide:construction) and [favorable-realization probability](result:favorable-probability).
